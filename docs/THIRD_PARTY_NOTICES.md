# Сторонние компоненты

Шрифты IBM Plex Sans поставляются локально через пакет @fontsource/ibm-plex-sans. Иконки — Lucide. Интерфейс — React / React DOM. Лицензионные тексты этих компонентов включены в `docs/licenses/`.

Браузерная SQLite — sql.js (MIT), SHA-256 — @noble/hashes (MIT); их лицензии также включены в `docs/licenses/`. Встроенная SQLite распространяется как public domain.

Версии всех библиотек зафиксированы в package-lock.json. Лицензии остальных зависимостей доступны в их пакетах после `npm ci`. Иллюстрации товаров — собственные SVG-схемы, без чужих фотографий. Из ATECH взяты визуальные принципы; исходные компоненты и эмблема не копировались.
